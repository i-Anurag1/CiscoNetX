# Protocol and Lab Coverage

Networking: OSI, TCP/IP, circuit and packet switching.

Data link: Ethernet, Wi-Fi concepts, MAC learning, VLAN, ARP, CRC, Checksum, Hamming Code, Stop-and-Wait, Sliding Window, Go-Back-N, Selective Repeat, ALOHA, Slotted ALOHA, CSMA, CSMA/CD, CSMA/CA.

Network: IPv4, IPv6, CIDR, subnetting, NAT, forwarding, Dijkstra, Distance Vector, RIP and OSPF concepts.

Transport: TCP handshake, reliable delivery, flow control, congestion window, slow start, congestion avoidance, retransmission and UDP.

Application: DNS, HTTP, HTTPS concepts, FTP, SMTP and SNMP flows.

Security: ACL, firewall, DDoS detection, port scan detection, ARP spoofing concepts, anomaly detection and rate limiting.
