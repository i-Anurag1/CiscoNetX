# Syllabus mapping

Networking fundamentals: OSI/TCP-IP concepts, topology, communication models.

Data link: Ethernet, VLAN, MAC learning, ARP, CRC, checksum, Hamming, Stop-and-Wait, Sliding Window, Go-Back-N, Selective Repeat, ALOHA, Slotted ALOHA, CSMA/CD, CSMA/CA.

Network layer: IPv4, IPv6, classful/classless addressing, CIDR, subnetting, NAT, routing tables, Dijkstra, Distance Vector, RIP and OSPF-style route behavior.

Transport: TCP handshake/state machine, ACK/retransmission concepts, congestion window, slow start, congestion avoidance, fast retransmit, UDP, QoS.

Application: DNS, HTTP, HTTPS, FTP, SMTP and SNMP flows.

Security: firewall/ACL evaluation, DDoS detection, port-scan detection, ARP-spoof detection and IP/MAC anomaly analysis.

Operations: SDN-style flow rules, traffic engineering, telemetry, deterministic replay, audit events, experiments and reports.

AI/ML: synthetic telemetry generation, baseline anomaly scoring, Logistic Regression training/evaluation and grounded network-state explanations.
